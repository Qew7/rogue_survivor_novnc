# Rogue Survivor в Docker

Игра запускается в Linux-контейнере, окно и управление доступны через noVNC
в браузере. На хосте нужны только Docker с Compose и браузер; XQuartz,
Mono и .NET устанавливать не нужно.

В этом репозитории **нет исходников и ресурсов игры**. Перед первой сборкой
распакуйте исходный архив Rogue Survivor alpha 10.1 и скопируйте его папку
`WRogue` в корень этого репозитория, рядом с `Dockerfile`. В ней должны быть
`RogueSurvivor.csproj`, файлы C#, `Resources` и остальные файлы исходного архива.
Папка `WRogue`, сохранения и прочие файлы игры исключены из Git.
Все изменения совместимости применяются скриптом `docker/prepare.py` только
к копии исходников внутри стадии сборки Docker.

```sh
git clone https://github.com/Qew7/rogue_survivor_novnc.git
cd rogue_survivor_novnc
# Скопируйте сюда папку WRogue из исходного архива игры.
```

```sh
docker compose up --build -d
```

Откройте [http://localhost:6080](http://localhost:6080).
Щёлкните внутри окна игры, чтобы передать ему клавиатурный фокус.
При первом запуске подтвердите создание каталогов клавишей Enter.
Для движения можно использовать стрелки; остальные клавиши указаны в меню
Redefine keys и Game Manual. Клавиатурную раскладку лучше переключить на английскую.

Первоначальная сборка скачивает компилятор и Linux-пакеты. Повторный запуск:

```sh
docker compose up -d
```

Остановка:

```sh
docker compose down
```

Сначала сохраните игру клавишами Shift+S (по умолчанию): остановка Docker не сохраняет текущую
партию автоматически. Закрытие вкладки лишь отключает просмотр, игра продолжает
работать. Выход из самой игры останавливает контейнер; снова запустите его
командой `docker compose up -d`.

Сохранения, настройки и журнал находятся в именованном томе `game-data`,
смонтированном в `/opt/game/Config`. Они переживают пересборку и `docker compose down`.
Команда `docker compose down -v` удалит этот том вместе с сохранениями.
Скопировать данные на хост из работающего контейнера:

```sh
docker compose cp game:/opt/game/Config ./game-data-backup
```

Диагностика:

```sh
docker compose ps
docker compose logs --tail=100 game
```

Если порт занят, выберите другой: `ROGUE_PORT=6081 docker compose up -d`,
затем откройте `http://localhost:6081`. Порт опубликован только на localhost;
VNC-порт наружу не публикуется. Это локальная сессия без пароля, все вкладки
управляют одной игрой.

## Особенности сборки

- Debian, Mono, GDI+, Xvfb, Openbox, x11vnc и noVNC находятся в контейнере.
- Современный компилятор C# используется только на стадии сборки, игра работает
  под Mono. `docker/build.py` создаёт Linux-вариант исходного проекта.
- Символ `LINUX` выбирает GDI+ и отключает Windows-зависимые DirectX/SFML.
  В этой версии **нет звука**.
- `MONO_IOMAP=all` обеспечивает совместимость исходных Windows-путей
  ([документация Mono](https://www.mono-project.com/docs/advanced/iomap/)).
- Виртуальный экран — 1280×800; noVNC масштабирует картинку по размеру вкладки.
- Архитектура контейнера выбирается Docker автоматически; принудительная
  эмуляция x86 не включена. На Linux используется та же команда Compose.

Проверено на macOS ARM64 с Docker Desktop: сборка ARM64-контейнера,
HTTP и WebSocket/VNC, изображение игры, клавиатурное управление,
создание партии, сохранение и загрузка после пересоздания контейнера.
Запуск на отдельном Linux-хосте и сборка AMD64 пока не проверялись.
